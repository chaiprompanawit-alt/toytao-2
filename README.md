# 🎲 ทอยเต๋าวงเหล้า (toytao-2)

เว็บแอปทอยลูกเต๋า 2 ลูก (แต้ม 1–6) สำหรับเล่นในวงเหล้า เป็นไฟล์ HTML ไฟล์เดียว เปิดได้เลยในมือถือหรือคอม ไม่ต้องติดตั้งอะไร

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages ก็ได้

## ฟีเจอร์

- ลูกเต๋า 3D 2 ลูก กลิ้งหมุนบนโต๊ะสักหลาดตอนทอย ใช้ `crypto.getRandomValues` สุ่มแต้ม
- เพิ่มรายชื่อผู้เล่น ระบบผลัดตาให้อัตโนมัติ แตะชื่อเพื่อข้ามไปคนนั้นได้
- กติกาดื่มตามแต้มที่ออก และนับจำนวนอึกที่แต่ละคนดื่มไป
- ประวัติการทอย 100 ครั้งล่าสุด
- จำผู้เล่นและประวัติไว้ในเครื่อง (localStorage) ปิดแล้วเปิดใหม่ยังอยู่
- กด Space บนคอมเพื่อทอยได้

## กติกา

| แต้ม | กติกา |
|---|---|
| ออก 7 | คนทางซ้ายกิน |
| ออก 8 | คนทางขวากิน |
| ออก 9 | เจ้า (คนทอย) กินเอง |
| ออกเบิ้ล (1-1 … 6-6) | คนทอยเลือกใครก็ได้ให้กิน (มีปุ่มเลือกชื่อ) |
| อื่น ๆ | รอด ส่งเต๋าต่อ |

ผู้เล่นเริ่มต้น 6 คน: มี่, แรม, แอม, วิว, โอเว่น, น็อต (เพิ่ม/ลบได้ในแอป)

แก้กติกาได้ในฟังก์ชัน `judge()` ใน `index.html`

ดื่มอย่างรับผิดชอบ เมาไม่ขับ 🍻
